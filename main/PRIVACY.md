# 公开材料与隐私边界

dev 保存完整本地开发、测试夹具、需求原文和安装记录；main 与 release 只提供可公开材料，不含真实会话、个人账户、安装 profile、本机配置和完整用户提示词。

公开内容保留任务所需语义和结构。不需要的私人数据移出发布范围，需要说明结构时采用一致占位符或明确虚构测试数据。个人信息、商业秘密、知识产权分别审查；内部密码、服务器地址、密钥和连接串不公开。第三方资源按许可保留必要内容与署名。

门禁检查机器路径、会话标识、联系方式、证件、令牌、私钥、凭据和服务器地址。发布前扫描整个公开源码及实际发布文件；解包后逐文件哈希核对并复扫。误放在 main 的本机报告不能靠打包排除逃过公开源码检查。

模式扫描不能识别所有商业秘密或身份，仍需材料来源、语义和许可审查。开源依赖保留各自公开授权，不为模式误报修改第三方代码。源码不含本地依赖缓存和开发二进制，发布包依赖清单可审计。

完整模型任务导出只留本地，公开交付使用独立脱敏摘要。未脱敏旧包移入 dev 档案，保留原字节和原校验和。
