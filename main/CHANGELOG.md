# 版本改动 / Version history

历史条目描述当时版本；现行行为以 3.0.3 文档为准。

## 3.0.3

修复共享样式卸载造成的界面退化，缩短状态标签并限制宽度、视口浮层。三阶段只用于套件自建调度编排模式；其他预设开始时一次多层对照，完成后仅显示“已经编排”。移除重复计划/委派引擎、工具过滤和其他预设中的完整流程注入。理解先进入系统上下文并由模型汇报，阶段与证据在任务进度展开呈现。

Fixes shared-style disposal and crowded header controls. Limits the full workflow to the suite preset; other presets receive one layer comparison and a compact result. Removes competing planning/delegation services and tool filters, with live preset switching and middleware passthrough coverage.

## 3.0.2

复用 DSH 验证器，按证据设置/展示规划工具路由、实际裁判模型与评分。装配认识、具体计划和初始待办写入系统上下文；执行认识驱动增量待办/计划并支持重读依据。交付结论独立系统 section；建设需求含项目缺项、问题及套件建议。双语说明、短发布说明与版本记录。

Reuses DSH verifier tools with task route controls and actual judge evidence. Adds integrated understanding, initial todos, execution insights, checkpoints, structured conclusions and suite feedback. Adds bilingual documentation and version records.

## 3.0.1

修复“引导即跳过”：11 环节实际查看并公开理解，短输入不跳过，装配不可绕过规划验证。待办无变化显式评估，重复输入仍要查看。交付实际尝试验收，理解绑定本次尝试；新证据使旧验收失效。界面区分缺口/无变更/失败，显示宿主实际版本。

Ordered inspection with advisory execution, explicit no-change decisions, mandatory delivery attempts, per-attempt understanding and runtime version visibility.

## 3.0.0

平铺流程改为三阶段、11 步；初始输入与补充原文分别保留；规划版本、待办历史、阶段身份和完整提示词导出。该版放宽环节可略过的行为在 3.0.1 修复。

Three phases, eleven steps, immutable original prompts, supplements, plan/todo histories, identities and full exports. Overly permissive skipping was corrected later.

## 2.3.2

改善可移植发布、环境配置、打包及解包校验，不改运行功能。

Portable packaging, explicit environment configuration and archive verification.

## 2.3.1

合并重复的状态与详情列表为原生折叠阶段行；灯、名称和状态持续可见，展开状态在刷新中保留。阶段分别保存错误原因，重试清除旧原因；看板资源统计和会话选择/响应一致性修复。详见 [迭代原始记录](docs/ITERATION-2.3.1.md)。

Unified expandable stage rows retain status and expansion state. Fixed per-stage diagnostics, visible resource counts and session/response consistency.

## 2.3.0

五层资料展示和记忆分类、协议/端口公开查询记录；身份/团队能力候选与分诊显示，新增 relic_record_observation。阶段位置、降级计数、证据和刷新超时；修复冻结注册表、重复根目录及可选服务访问。详见 [迭代原始记录](docs/ITERATION-2.3.0.md)。

Added five-layer presentation, categorized memory transport observations and public identity/team candidates. Improved scoped reports, degraded status and polling; fixed frozen registries, duplicate roots and optional-service access.

## 2.2.0

独立看板和标题栏进度；公共能力发现、系统 section 和原验证器复用；升级保留其他插件和预设。模式当时名称较长，3.0.0 起统一“调度编排模式”。

Independent board/header progress, public discovery, system sections and existing verifier integration with scoped deployment.

## 2.1.0

仅保留历史基础包，缺少可复核逐项清单，不补造变更。

No reliable per-change record is available for the historical base version.
